The band that ends every page: one promise, one button, an email fallback.

- **Markup:** `section.closing` > `.closing-orbit` (decorative) + `.closing-inner`: eyebrow with status dot, `h2` whose second half is wrapped in a `span` (turns `red`), `.lead`, `.button`, `.email`.
- **Specs:** `surface-closing` ground, `red-border` rules, `section-y` padding, `closing` heading style. The orbit is a 900px circle in `radius-round` with `shadow-orbit`, cropped off the right edge.
- Copy pattern: restate the hero promise, then a concrete, low-commitment offer ("A 20-minute conversation…"). The email link is the only underlined link outside prose.
