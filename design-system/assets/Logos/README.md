The heydru! marks. The SVG files live in this repo's `svg/` folder (PNG renders in `svg/png/`); heydru.com serves byte-identical copies under `/brand/svg/`.

- **logo-on-dark.svg** — the default horizontal lockup on `bg`: red mark (#F0216C) with a white wordmark.
- **logo-on-light.svg** — the same lockup on white: red mark with a #393A3E wordmark.
- **logo-on-dark-mono.svg** — all white. Use it on red, photos, or single-ink dark contexts where the red mark would clash.
- **logotype-on-dark.svg / logotype-on-light.svg** — the wordmark alone (white / #393A3E). Use it only when the mark already appears nearby.
- **lockup-vertical-on-dark / -on-light / -on-dark-mono.svg** — the mark stacked above the wordmark, for square formats.
- **icon-mark-red.svg** — the mark alone, single ink #F0216C. It is the favicon and avatar.
- **icon-mark-white.svg** — single ink #FFFFFF, for red or dark grounds.
- **icon-mark-black.svg** (#393A3E), **icon-mark-blue.svg** (#384993), **icon-mark-yellow.svg** (#FFEA2E) — print and illustration alternates from the 2021 brandbook. Don't use them in the web UI.

Keep clear space equal to one icon-mark width on every side. These are fixed-ink files, so pick the one whose ink suits the ground rather than recoloring.
